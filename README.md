# Dashboards Personal

Colección de ejercicios y proyectos de visualización orientados a presentar información mediante indicadores y dashboards.

## Objetivo

Practicar la selección de métricas, organización de información y diseño de visualizaciones para facilitar la interpretación de datos.

## Enfoque

- Definición y organización de KPIs.
- Presentación de información comercial.
- Diseño de dashboards.
- Comunicación visual de resultados.

## Relación con el perfil profesional

Este repositorio complementa el proyecto de análisis de ventas y demuestra interés en Data Analytics y Business Intelligence.

## Alcance

Material de práctica y formación. Los proyectos deben interpretarse junto con su documentación específica cuando esté disponible.
